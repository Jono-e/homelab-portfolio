# ⚙️ DevOps / Kubernetes Lab

> 🔄 **In Progress** — This lab is currently being built. Check back for updates.

---

## Planned Content

This lab will cover the DevOps and container orchestration skills most commonly required in cloud-adjacent roles:

- **Docker** — containerising applications, networking, volumes, compose
- **Kubernetes (k3s)** — lightweight k8s cluster on VirtualBox VMs, deployments, services, ingress
- **CI/CD** — automated build and deployment pipeline (GitHub Actions or Jenkins)
- **Infrastructure as Code** — Ansible for configuration management, basic Terraform

---

## Environment (Planned)

- 1x control plane node (Ubuntu Server VM)
- 2x worker nodes (Ubuntu Server VMs)
- k3s (lightweight Kubernetes — production-grade, designed for resource-constrained environments)
- All running on VirtualBox with host-only networking
