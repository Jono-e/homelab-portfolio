 Homelab Portfolio

A hands-on collection of home labs built to develop and demonstrate real-world IT skills across Linux system administration, cybersecurity, and DevOps. Each lab was built from scratch using VirtualBox on a Windows host with 16GB RAM, simulating real enterprise environments and workflows.

These labs were built to back up the skills on my CV with practical, documented evidence — not just theoretical knowledge.

| Lab | Skills Demonstrated | Status |
|-----|-------------------|--------|
| [Linux Sysadmin Lab](./linux-lab/README.md) | User management, services, networking, scripting, troubleshooting |  Complete |

| [DevOps / Kubernetes Lab](./devops-lab/README.md) | Docker, Kubernetes (k3s), CI/CD, infrastructure as code |  In Progress |

---

##  Environment

- **Host OS**: Windows 11 with Hyper-V (Docker Desktop WSL2 backend)
- **Hypervisor**: VirtualBox 7.x (running alongside Hyper-V in compatibility mode)
- **VMs**: Ubuntu Server 26.04 LTS, Kali Linux, Metasploitable2
- **Networking**: Bridged adapter (sysadmin VM), Internal Network isolation (security lab)

---

##  Purpose

Built to strengthen job applications for Linux support, sysadmin, and junior security roles. Each lab includes real troubleshooting scenarios, documented findings.
